# mipt_cv_26_autumn

Курсовой проект «Разные методы генерации из диффузионных моделей» 

МФТИ, осень 2026

## Этап 1 — рубежный контроль

| Файл | Описание                                                                                                                                                                                                                                                                     |
|---|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `report.md` | Отчёт по этапу 1: разбор методов, данные и модели, метрики, воспроизведение baseline, план этапа 2                                                                                                  |
| `stage1_baseline.ipynb` | Ноутбук этапа 1: обвязка модели `google/ddpm-cifar10-32`, воспроизведение baseline (DDIM из Diffusers) с метриками FID / число шагов / время, проверка качества vs число шагов. Вся теория, метрики и планы — в `report.md` |
| `figs/` | Картинки для отчёта (из результатов ноутбука)                                                                                                                                                                                                                                |
| `prepare_data.py` | Подготовка данных: фиксированный набор из 1000 шумов (seed 2026), CIFAR-10 test → PNG, FID-статистики референса                                                                                                                                                              |

Данные и артефакты (`data/`, в `.gitignore`) восстанавливаются запуском `prepare_data.py`.
